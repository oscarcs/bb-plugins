# BB plugins

Personal plugins for BB.

- [Violet & Usage](./bb-plugin-violet-usage/README.md) — a purple-blue palette and compact provider usage bars.

- [Google Antigravity (ACP)](./bb-plugin-antigravity-acp/README.md) — Google Antigravity ACP provider backed by the official Antigravity CLI (`agy acp --stdio`) with per-model reasoning levels, Auto mode OS sandboxing, unsandboxed Full access mode, BB runtime directory access, and Provider Usage quota bars.
